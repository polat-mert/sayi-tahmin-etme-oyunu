# Sayı Tahmin Oyunu

Python kullanılarak geliştirilmiş basit bir sayı tahmin oyunu.

## Oyunun amacı

Bilgisayarın 1 ile 100 arasında tuttuğu sayıyı en fazla 7 tahminde bulmaya çalışmak.

## Özellikler

- 1 ile 100 arasında rastgele sayı üretir
- Kullanıcıya 7 tahmin hakkı verir
- Tahminin büyük veya küçük olduğunu belirtir
- Hatalı girişleri kontrol eder
- Oyun bittikten sonra tekrar oynama seçeneği sunar

## Kullanılan teknoloji

- Python
- `random` kütüphanesi

## Çalıştırma

Terminalde şu komutu çalıştır:

```bash
python main.py 
```
 ## Öğrendiklerim
- Değişkenler
- Fonksiyonlar
- while döngüsü
- if, elif, else koşulları
- try-except hata kontrolü
- Kullanıcıdan veri alma
- Rastgele sayı üretme
